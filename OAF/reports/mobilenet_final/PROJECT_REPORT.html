Executive summary

This report documents an eight-phase effort to produce a single, small, deployable convolutional network that grades knee osteoarthritis (OA) severity from a plain radiograph on the Kellgren–Lawrence (KL) 0–4 scale, and runs on a screen-connected Raspberry Pi.

The work proceeded from a rigorous dataset audit, through a controlled 15-architecture benchmark, to architecture-specific tuning and finally knowledge distillation from larger teacher networks into MobileNetV2. The distilled model improves on the untuned MobileNetV2 baseline by +2.6 Macro-F1 points and +3.9 QWK points at identical parameter count, while a controlled label-scheme study quantifies exactly how much accuracy is bought by collapsing grades.

Principal results (frozen test set, n = 1,240)

  • 5-class KL grading: accuracy 0.661, Macro-F1 0.681 (0.686 ± 0.007 across three seeds), quadratic-weighted κ 0.835, within-±1-grade accuracy 0.954.
  • Binary OA screening (KL0–1 vs KL2–4), derived from the same probabilities: ROC-AUC 0.941, specificity 0.97 at the default operating point.
  • Three-class (Normal / Early / Advanced): accuracy 0.765.
  • Efficiency: 2,230,277 parameters, 8.9 MB fp32 ONNX, 0.31 GMACs, ~3.5 ms per image on one CPU core, ~92 MB RSS.

On the “>90%” question, stated plainly: 5-class KL accuracy at 90% is not attainable by any model on this data. It is a property of the labels, not of network capacity — radiologist-versus-radiologist agreement on the KL scale is roughly 60–70%, and published state of the art on the same source sits near 70–75% accuracy. The clinically meaningful, defensible strong claim from this work is a binary OA-screening AUC of 0.94. Where a headline accuracy figure nearer 90% is required, the label-scheme study (§08) shows a 4-class grouping reaching 0.79 accuracy / 0.76 Macro-F1 — at the cost of the KL0/KL1 distinction.

Problem and objectives

Knee OA is graded radiographically on the five-point Kellgren–Lawrence scale: KL0 normal, KL1 doubtful, KL2 minimal, KL3 moderate, KL4 severe. The target deployment is a low-cost, offline, screen-connected device (Raspberry Pi class) that assists a clinician by proposing a grade and an OA / no-OA screen from a single anteroposterior knee film.

The engineering objectives, fixed at the outset:

  1. Strong ordinal grading performance — measured primarily by Macro-F1 and quadratic-weighted κ, never by accuracy alone.
  2. High sensitivity / specificity for the clinically meaningful OA screen.
  3. Improved behaviour on the difficult early-disease (KL1) boundary.
  4. A single MobileNetV2-class model — low parameter count, small on disk.
  5. Low CPU inference latency and memory, exportable to an edge runtime.
  6. No data leakage; a completely untouched final test set.
  7. Reproducible, seed-controlled evaluation.

Scope boundary. This module is the X-ray grader only. Gait / inertial sensors, the WOMAC questionnaire, any language model, the mobile application, Bluetooth transport and multimodal fusion are explicitly out of scope and were never implemented.

Dataset, provenance and leakage control

The image source is the Kaggle Knee Osteoarthritis Dataset with Severity Grading (shashwatwork): 9,786 PNG knee regions of interest, uniformly 224 × 224, 8-bit grayscale, 0 corrupt, 0 unreadable.

Provenance — verified, not assumed

Every one of the 4,130 patient identifiers parses to an OAI participant ID, and all 8,260 train+val+test knees match the OAI baseline visit (00m) KL grade exactly (0 disagreements). The Kaggle images therefore are the OAI 00m per-knee ROIs. Two consequences were treated as hard constraints:

  • The separate OAI metadata repository contains no pixel data — it cannot serve as additional training images or as an independent external test set (same patients).
  • The Kaggle auto_test folder is a re-detection of the same test knees with different crops and 21 conflicting labels; it was excluded from the working set to prevent leakage, and retained in the manifest only for optional robustness checks.

Leakage audit

  • Exact duplicates (SHA-256) across all 9,786 files: 0.
  • Same knee appearing in more than one split: 0.
  • Perceptual near-duplicates (pHash Hamming ≤ 4): 184 within the working set, all cross-patient look-alikes at 224 px — not the same scan, not leakage.
  • Automated validation: 29 / 29 checks pass.

Should more data be added? No. The question was answered empirically. There is no compatible independent dataset available: the only other OAI-derived source shares the same patients, and merging it would place identical scans on both sides of the train/test boundary. The strategy was fixed as keep the current data; improve through training method, not volume.

Phase 1 — data pipeline

A deterministic pipeline (identical for train, validation and test) was materialised: read → grayscale → validate → ROI (no-op; images are already knee ROIs) → pad-to-square → resize 224 → contrast variant. Three contrast variants (basic, CLAHE, histeq) were written to disk losslessly so the contrast choice could be an ablation rather than an assumption.

For pretrained ImageNet backbones the grayscale image is replicated to three channels (never colourised) and ImageNet-normalised at load time. Class weights were computed from the training split only. Augmentation is train-only and clinically constrained — small rotation, translation, scale and shear, horizontal flip (KL grade is side-agnostic and left/right is already normalised per file), mild brightness/contrast, light noise. Vertical flip, large rotation, elastic warp and random erasing are disabled because they distort the joint-space and osteophyte cues that define the grade.

Phases 2–5 — the 15-architecture benchmark

Fifteen ImageNet-pretrained architectures were trained under one identical recipe — weighted cross-entropy, two-stage transfer (head-only then full fine-tune), cosine schedule, AMP, seed 42, early stopping on validation Macro-F1 — then evaluated once on the frozen test set. The purpose was to establish the accuracy ceiling on this data and to place MobileNetV2 within it.

What the benchmark established

  • The best model on this data (VGG16, Macro-F1 0.738) sits at published state of the art — roughly 0.70–0.75 accuracy is the field ceiling for 5-class KL on OAI.
  • KL1 “doubtful” is the universal weak class. The best KL1 F1 across all fifteen models was 0.49 (VGG16); most fell between 0.25 and 0.43. KL1 is defined by reader uncertainty, so it carries the label noise.
  • KL4 “severe”, despite only 176 training knees, is classified well (F1 0.83–0.95): end-stage disease is visually unambiguous. Small does not mean hard.
  • MobileNetV2 is edge-ideal (2.23 M params) but ~8 Macro-F1 points below the large models. Closing that gap without growing the model is the remaining problem.

Phase 7 — MobileNetV2-specific tuning

MobileNetV2 had been trained only under the generic 15-model recipe. Phase 7 ran a controlled matrix changing one dimension at a time: differential learning rates, focal loss, class-balanced loss, a milder inverse-frequency sampler, CLAHE, a wider “strong-but-medical” augmentation set, and a CORN ordinal head. Each candidate was multi-seeded (42 / 123 / 3407).

The strong-augmentation MobileNetV2 reached test Macro-F1 0.669, and 0.696 with horizontal-flip test-time augmentation (which is exact under per-channel normalisation and consistent with a side-agnostic grade). Stacking the winning dimensions over-regularised the 2.23 M-parameter network and did not beat the single best change. CORN looked best on validation but was unstable across seeds and destroyed KL1 on the test set — a clean negative result.

Phase 8 — knowledge distillation

With architecture tuning exhausted, the remaining lever was the training signal itself. The frozen VGG16 and ConvNeXt-Tiny models from the benchmark were used as teachers: their softened class probabilities were cached once per training image, and the MobileNetV2 student was trained on a blend of the teacher distribution and the hard label.

Distillation objective

L = α·T²·KL( softmax(teacher / T) ‖ softmax(student / T) )
    + (1 − α)·CE( student, hard label ; class weights )

Temperature T = 4, distillation weight α = 0.8 in the winning configuration; teacher = weighted mean of VGG16 and ConvNeXt-Tiny; weight EMA on; 70-epoch schedule.

Distillation delivered a genuine, reproducible lift: +3.2 validation Macro-F1 points with TTA over the no-distillation control (0.643 → 0.686), and +1.9 over the Phase-7 tuned model — at the same 2.23 M parameters. A single ConvNeXt teacher outperformed the VGG16+ConvNeXt ensemble at equal α; the ensemble only won once α was raised to 0.8 with EMA and a longer schedule. Mixup and label smoothing did not help.

Label-scheme study

A recurring question was whether merging grades would raise accuracy. It was answered with a controlled sweep: the same distillation recipe trained on four label schemes, each scored once on the test set.

Table 6. Label-scheme sweep. Same KD-MobileNetV2 recipe; test set scored once per scheme. Parameter count is constant — only the final layer width changes.
SchemeClassesTest AccTest Macro-F1Test QWKTest AUC
5-class KL (standard)50.6750.6940.839—

Binary — No-OA / OA20.8690.862—0.943

Reading the sweep

  • Merging KL4 into KL3 was rejected before running. KL4-F1 is already ~0.88; it is a small but easy class. Folding it into KL3 would delete a high-scoring class from the macro average and dilute KL3 — projected Macro-F1 drop from 0.67 to ~0.62.
  • Merging KL0 and KL1 is the merge that helps. KL1 (F1 ~0.33) is the weak class and the KL0↔KL1 boundary holds the label noise. Collapsing it lifts accuracy to 0.79 and Macro-F1 to 0.76 — but note QWK actually falls slightly (0.839 → 0.824): the scale is coarser, so each remaining error costs proportionally more, and KL2 absorbs the freed ambiguity (its F1 drops to 0.48).
  • The 3-class grouping is the worst option here — QWK 0.66 — because “Normal vs Early” is still the KL0/KL1 decision under a new name.
  • Binary is the strongest clinical framing: AUC 0.943, accuracy 0.87.

Decision. Deploy the 5-class model as the engine. It has the best ordinal agreement (QWK 0.835), honours the clinical KL standard, and the binary OA screen and 3-class view are derived from its probabilities at inference time (P(OA) = P₂ + P₃ + P₄). One model serves every granularity. The 4-class scheme remains available for contexts where a higher headline accuracy matters more than the KL0/KL1 distinction.

Calibration and selective prediction

Raw softmax confidences were over-confident (expected calibration error ≈ 0.10). A single temperature parameter, fitted on validation negative log-likelihood (T = 1.39), roughly halves it. All reported probabilities are temperature-scaled.

A confidence threshold for automatic acceptance was chosen on validation for a target 90% selective accuracy, giving a deployment policy:

Edge deployment

Inference is torch-free: NumPy + OpenCV preprocessing and ONNX Runtime on CPU. The model is a single self-contained fp32 .onnx file; parity with the PyTorch checkpoint is exact (max |Δlogit| ~1e-5, argmax agreement 64/64 on a held-out test slice).

Table 12. Latency and footprint. x86 single-thread ONNX Runtime, batch 1, 224² input; a Raspberry Pi 4 CPU is roughly 4–10× slower.

int8 was rejected. Dynamic (weight-only) int8 quantization degrades MobileNetV2 badly — argmax agreement with fp32 was only 33/64 on the test slice, because per-tensor quantization of depthwise-separable convolutions is lossy — and it is slower under the ONNX Runtime CPU int8 kernels on both x86 and ARM. The 8.9 MB fp32 model runs comfortably on a Pi; there is no reason to quantize.

System

Explainability — Class Activation Mapping

Every prediction is accompanied by a heatmap showing which region of the film drove the grade. MobileNetV2’s head is features → global-average-pool → Linear(1280→5) with nothing between the pool and the linear layer, so Grad-CAM’s per-channel weight αkc collapses algebraically to the classifier weight W[c,k] / (H·W) — a constant. The heatmap is therefore the original Class Activation Map (Zhou et al. 2016):

CAMc(x, y) = ReLU( Σk W[c, k] · featk(x, y) )

This is exact, not an approximation, and needs no gradients. It runs under plain ONNX Runtime (torch-free) from a second model output — the 1280-channel feature map — at a cost of +3.2 ms on one CPU core (1.4 → 4.7 ms per image). Logits from the CAM-enabled graph are bit-identical to the deployed model (max |Δlogit| = 0, argmax agreement 24/24 on a test slice), and the salient region fell inside the tibiofemoral joint band on 24/24 sampled test images.

From the map the system also derives a coarse focus descriptor (central joint line / one compartment / diffuse–bicompartmental, with a left-vs-right-of-joint hint) and a short templated interpretation: grade-typical radiographic findings (e.g. KL2 → “definite osteophytes; possible joint-space narrowing”) plus a grade-banded recommendation. The wording is generic and explicitly marked as AI-generated, not patient-specific.

Limitations and honest assessment

  • Single source. All data is OAI-derived; there is no independent external test set. Generalisation to other scanners, populations and positioning is unverified.
  • Label ceiling. Grades are single-reader OAI baseline reads. 5-class KL accuracy near 90% is not reachable — the noise floor of the labels is higher than that. This is not a shortcoming of the model.
  • KL1 remains weak (F1 0.33). “Doubtful” is the disagreement class by construction; no model in the benchmark exceeded 0.49.
  • KL4 confidence intervals are wide — 38 test knees.
  • Pre-cropped 224² input. Original full radiographs and true pixel spacing are unavailable, so joint-space width in millimetres and higher-resolution features cannot be used.
  • Not a diagnostic device. The KL grade is a radiographic scale, not a complete clinical OA diagnosis. Every output carries an “AI-assisted — clinical correlation required” disclaimer.

Conclusion

The deliverable is one MobileNetV2 network of 2.23 M parameters and 8.9 MB that grades knee OA on the full Kellgren–Lawrence scale at Macro-F1 0.681 and quadratic-weighted κ 0.835, screens for radiographic OA at AUC 0.941, calibrates well, abstains when uncertain, and runs in a few milliseconds per image on a CPU. Knowledge distillation from larger teachers — not more parameters, not more data — supplied the decisive improvement over a tuned baseline, while a controlled label-scheme study makes the accuracy-versus-granularity trade-off explicit rather than assumed.

The project did not manufacture a >90% number. It established where the real ceiling is, reached a defensible strong result against the clinically appropriate task, and shipped a model that fits the target hardware.
